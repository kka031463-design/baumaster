# Bau Master: текущая реализация

Дата фиксации состояния: 2026-04-05

## Что изменено

- Убрано публичное упоминание `PIPE` из основных страниц сайта.
- Обновлены заголовки и описания калькулятора на формулировку "Калькулятор коммерческих предложений".
- Переработана генерация PDF-коммерческого предложения.
- Скачать КП теперь можно без авторизации.
- Скидки и сохранение в историю оставлены только для администратора.
- Добавлено редактирование ранее сохранённых КП через историю.
- Обновлены встроенные тексты справки/документации в приложении.

## Текущая реализация по страницам

### Публичные страницы

Изменены файлы:

- `about.php`
- `index.html`
- `price.php`
- `calculator_embed.php`
- `calculator/index.html`

Текущее состояние:

- слово `PIPE` в публичных заголовках и ссылках убрано;
- основной публичный заголовок калькулятора: `Калькулятор коммерческих предложений`.

### Калькулятор

Основная логика находится в собранном файле:

- `calculator/assets/index-tkN8zywe.js`

Текущее поведение:

- калькулятор позволяет сформировать КП без входа администратора;
- блок клиента доступен без авторизации;
- при отсутствии авторизации скидки в интерфейсе не показываются;
- без авторизации скидки также не попадают в PDF;
- без авторизации КП не сохраняется в историю;
- при авторизации доступны скидки, история и редактирование сохранённых КП.

### История КП

Текущее поведение:

- в историю сохраняются только административные КП;
- для сохранённых записей добавлено действие редактирования;
- при выборе редактирования данные КП переносятся обратно в калькулятор через localStorage;
- после возврата в калькулятор черновик редактирования подхватывается автоматически.

Используемый ключ localStorage для черновика редактирования:

- `pipe_calc_edit_draft`

### PDF-коммерческое предложение

Текущая реализация PDF:

- убран столбец цены из спецификации изделий;
- убран блок поставщика;
- убраны реквизиты, телефон, почта и нижний служебный блок Баумастера;
- убраны лишние синие/цветные полоски;
- убрана диаграмма/служебная картинка типа `measurement-diagram`;
- слово `PIPE` из PDF убрано;
- состав комплекта свёрстан компактнее;
- если изображений немного, они остаются на текущем листе;
- если изображений много, они переносятся на следующий лист;
- в PDF остаётся только необходимая информация по КП и составу комплекта.
